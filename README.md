# 文字基因编码器 · Unicode Gene Encoder 🧬

> 一个 vibe coding 出来的文字/Gene 编码器：把文字变成 ATCG 碱基序列再变回来，顺路做了口令加密、酶切、CRISPR、突变进化、基因音乐和 3D 双螺旋。
> HTML + Cordova 封装，欢迎提出交流意见喵。

你没看错：这是一个能把「今天也要开心鸭」变成 `TATAAT...TAA` 一整条基因序列的工具。
每个汉字、每个 emoji（真的，emoji 也行）都会被编码成 **9 个碱基**，装在真实生物的启动子 `TATAAT` 和终止密码子 `TAA` 之间，看起来就像一条刚从测序仪里吐出来的基因。

而解码是严格可逆的——一个碱基都不会丢。毕竟，谁也不想把「今天也要开心鸭」测回来变成「今天也要难受鸭」。

校验值镇楼：`汉` = `AGCTAGACG`。

### 挑几个好玩的展开说

**杂交实验室**：红色大狗 × 蓝色小猫 = 红色大猫、蓝色小猫……每个字是一个性状，9NT 整块遗传，所以你永远生不出半红半蓝的字——但单点交叉、双点互换、均匀抽签三种重组方式各有各的遗传学梗。

**突变 & 定向进化**：点突变 / 缺失 / 插入 / 倒位，插入缺失会移码、下游全员乱码（和真实基因一样惨烈）。定向进化披着进化外衣干优化算法的活：无性是 (1+8) 进化策略必收敛；有性是 12 株锦标赛选亲 + 单点交叉 + 精英保留，群体条掉到 1/12 多样性还会提醒你「近交了」。

**五音盒**：宫商角徵羽 ↔ 碱基。化学语义预设下，互补碱基对各落纯五度——双链一起听是谐和的；转换突变听成大二度、颠换听成大六度，**突变类型靠耳朵就能分辨**。

**哈夫曼**：4 进制哈夫曼把定长 9NT/字 压到 ≈3.6 NT/字，省 60%。但真实 DNA 存储偏偏不用变长码——均聚物会把码边界砸得稀碎。本工具对此的态度是：知道，但先玩为敬。

**合成体检**：GC 含量、均聚物、重复片段、克隆位点冲突——这条序列要是真送去合成公司能不能接单，先自己体检一下。

## 核心原理（30 秒版）

```
文字 → Unicode 码点（低 18 位）→ 3×6bit → 四进制 0-3 → A/G/C/T → 每字 9NT
TATAAT [ 密文：每字 9NT ] TAA
帧头(真实启动子)         帧尾(真实终止子)
```

- **定长双射**：9NT 组 ↔ 码点一一对应，解码严格可逆；U+40000 以上的码点超出 18 bit，提示跳过。
- **口令加密（混淆级）**：口令 → cyrb128 摘要 → mulberry32 PRNG → 碱基替换表打乱 + 每字独立的三联体置换。口令错一个字母，解出来就是等概率的乱码。
  ⚠️ 诚实声明：密钥空间小、PRNG 非密码学安全，这是**混淆级**加密，防随手窥探和好玩用的，不是密码学强度。
- **转录&翻译**：DNA→RNA→蛋白质走标准密码子表（64→21 多对一），所以氨基酸方向回不来——同义性在翻译那一刻就熵减了，任何函数都捞不回来。想严格可逆请走 RNA / DNA 密文。

更细的算法推导、设计动机和「哪些地方形似神非」，见 [FUNCTION.md](FUNCTION.md) 的逐界面说明。

## 隐私：这玩意儿干净得离谱

可以拍胸脯：

- **零网络代码**：fetch / XHR / WebSocket / sendBeacon 一个都没有，无统计无埋点。唯一的外部访问是 HTML 版 3D 界面在本地 `vendor/` 缺失时从 CDN 拉 Three.js（APK 版已内置，完全不触网）。
- **零存储**：localStorage / sessionStorage / cookie / indexedDB 全部没用。你输入的文字和口令只活在内存里，关掉页面就蒸发。
- **零第三方代码**：单文件 HTML，字体走系统栈，图标是手绘内联 SVG，连 logo 都是 base64 内嵌的。
- APK 权限只有 Cordova 必需的 `INTERNET`（外加一个实际拿不到授权的系统级 `DUMP`）；唯一自定义插件 backup-saver 只做「把导出文件写进下载目录再弹系统分享面板」。

## 技术细节

- 单文件 HTML，内联 CSS + JS，全部 ES5（`var` / `function`），无框架无构建。
- 白纸主题：8pt 网格、发丝分割线、无阴影、无圆角卡片，浅色点阵 + SVG 噪点背景。
- 支持中文输入法（组词期间不触发编码）；整页禁缩放，唯一例外是 3D 画布。
- 实测性能（Chrome）：15009 nt 解码 141 ms；酶切全流程（6 种酶、2609 位点）933 ms；3D 400 bp 自动旋转 60 fps。
