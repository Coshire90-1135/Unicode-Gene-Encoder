ALGORITHM · 算法注记 像进化，不是进化
定向进化：无性 = (1+8) 进化策略 + 精英保留——每代 8 个克隆各做 1~3 次点突变，与目标 DNA 逐位比相似度，只保留更高的；地形逐位可加、无局部最优，所以单点变异爬山必然收敛。有性 = 12 株群体：锦标赛选双亲，单点交叉重组（前段取一个亲本、后段取另一个，类比减数分裂的交叉互换），子代再点突变；精英 2 株直通，其余每代全部死亡。诱变：点突变 / 缺失 / 插入 / 倒位，均匀随机，只落密文区。
与生物基因突变的关系：看上去像，其实完全不是一回事。形似——变异、选择、遗传的循环都在（对应诱变、筛选、复制），有性模式连重组、群体、死亡也有了。神非——生物没有目标函数，适应度由环境事后决定；突变是带偏的化学事件，速率与位点各有偏好。这里的适应度始终是全知打分器给出的逐位相似度，本质是披着进化外衣的优化算法；群体条里多样性掉到 1 时，重组也就退化成了克隆（近交）。

ALGORITHM · 算法注记 有性生殖的本质
杂交：两个亲本文字各编码成一条基因，交叉点按整字（9NT = 1 字符）对齐——所以每个字作为一整个"性状"从某一个亲本整块遗传下来，子代文字逐字标色（绿底 = 来自亲本 A / 蓝底 = 来自亲本 B）。单点交叉：断点下游的性状连锁遗传（这就是摩尔根的基因连锁）；双点交叉：交换中间片段；均匀交叉：每个字独立抽签，自由组合的极端。点一次「杂交」重抽一次交叉点，4 株子代各不相同——有性生殖的关键就是后代多样。
与真实减数分裂的关系：像，但仍不是一回事。真实的重组发生在 DNA 层面、不按"字"对齐——错位的接缝会把基因打碎（对应本工具突变实验室里的移码乱码）；真实减数分裂的重组率随距离变化，介于完全连锁与自由组合之间；而且生物的杂交发生在群体里，配合定向进化舱的有性模式一起看。

ALGORITHM · 算法注记 香农 1951 的玩法
统计：语料的 0–3 阶字符 n-gram 计数；H0 = log2(字符集)，H1 单字熵，H2 / H3 = 相邻 2 / 3 字的条件熵（bit/字），阶数越高越可预测。
采样：阶 n = 给定前 n−1 个字，按语料中该前缀后面实际跟过的字里按频率抽一个；没见过这种前缀就逐级回退低阶。
LM 进化：同一副 (1+8) 进化策略，适应度换成 n 阶语言模型的平均 log2 概率；提议 85% 从语料字符集整字替换 + 15% 随机翻碱基（几乎总被拒绝）。有性变体：12 株群体按整字（9NT 一个字符）交叉重组，变异、精英与淘汰同前。
与生物基因突变的关系：看上去像，其实完全不是一回事。形似——都在序列上做变异与筛选。实非——生物的适应度由真实环境事后给出，没有模型、没有"像话"这种被定义好的目标；这里的环境是一个统计模型，被优化的其实是它自己；生物突变也不需要什么提议分布。

ALGORITHM · 算法注记 通路是真的
操作姿势：① 粘贴/载入菌株 → ② 在靶点表点选一行（高亮即选中）→ ③ 点 NHEJ（随机 indel，移码）或先填模板再点 HDR（整字块精确改写）→ ④ 修复会移动后续碱基位置，每次修复后靶点表自动重扫、选中自动清空，连续编辑就重复 ②③。
为什么有时点了没反应：NHEJ 需要先选中靶点（没选会提示）、删除不能吃进帧尾终止子（太贴近帧尾会被拒）；HDR 还需要先填修复模板——文字自动编码，DNA 模板必须 9NT 整数倍（否则移码，拒收）。两个键为什么"冲突"：indel / 替换都会让旧靶点位置失真，修复后不重选就再点，等于对着一张旧地图动刀——现在每次修复后强制重扫清空，没重新选靶点就不会落第二刀，这是防呆不是 bug。
靶点：SpCas9 只切 PAM（NGG）上游 3nt——扫描的是载荷区全部 NGG，剪切点按真实规则标注。NHEJ（非同源末端连接）：断口随机 indel（1–6NT），移码后下游全部乱码——真实细胞里 NHEJ 也是乱修。HDR（同源定向修复）：按模板精确改写，这里把靶点覆盖的整字块替换成模板（长度保持 9NT 倍数，不移码）。
与真实 CRISPR 的关系：通路是真的，尺度是玩具的。真实 sgRNA 约 20nt、HDR 需要带同源臂的供体模板、编辑效率远非 100%；这里把引导压成靶点表的一行、把供体简化成一个模板框——但 NHEJ 乱、HDR 准的对比是真实生物学。

ALGORITHM · 算法注记 定长省事，变长省料
4 进制哈夫曼：ACGT 是四符号字母表，每次把频率最小的 4 棵树合并成一棵（K−1 不够整除 3 时补零频虚拟字），高频字码短、低频字码长——每字平均 NT 数直接可与定长 9NT 对比。香农极限 H1 是任何编码都不可能低于的每字平均信息量（bit/字）。
那真实 DNA 存储为什么不用变长码：因为合成约束会砸碎码边界——均聚物跑出来的重复碱基让变长码无法断句，GC 极端区也不满足工厂约束。所以 DNA Fountain 等真实方案用固定长度 + 喷泉码把冗余花在纠错上，而不是压缩上；本工具的 9NT 定长同理。压缩率交给这一页算，可行性交给「合成体检」判。

ALGORITHM · 算法注记 距离与可解释性
距离：两株的距离 = 1 − 逐碱基相同比例（长度不齐按较长者归一）。UPGMA：反复合并最近的两个簇，簇间距离取成员平均，合并高度 = 距离 ÷ 2——它隐含分子钟假设（所有谱系演化速率相同），真实的建树还有邻接法 / 最大似然。亲子鉴定：孩子每个字位只要与某对候选中任一方的同位字相同即"可解释"（与杂交的整字遗传、缺位补位语义一致），可解释比例最高的对即最可能的亲本对。
像但不是一回事：真亲子鉴定看的是基因型频率统计（STR 位点 + 群体遗传学），不是逐字匹配；这里成立的每一分，都因为本工具的字真的是"整块遗传"的。
